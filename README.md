# Discovery Call Scorer
This program helps a new sales rep judge a discovery call. It asks four yes/no
questions (budget, decision maker, real problem, timeline), totals a score out
of 4, and rates the call as **Strong**, **Mediocre**, or **Not Ready**.
Each scored call is saved to `calls.txt`, and the menu can show a summary of
every saved call.

## How to Run
```
python main.py
```
No extra libraries are needed.

## Rating Scale
| Score | Rating |
|-------|--------|
| 4 | Strong |
| 2 - 3 | Mediocre |
| 0 - 1 | Not Ready |
